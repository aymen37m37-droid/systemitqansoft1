أولاً: إعدادات الفاتورة الرئيسية (Master Receipt)



يجب أن يوفر النظام إمكانية التحكم في:



عدد نسخ فاتورة الطلب الكاملة.

إمكانية تخصيص كل نسخة لغرض معين.



مثال:



نسخة رقم (1)



مخصصة خاصه بالزبون.



نسخة رقم (2)



مخصصة للكاشير.



نسخة رقم (3)



مخصصة للمحاسبة.



نسخة رقم (4)



مخصصة للأرشيف.



ويستطيع مدير النظام تغيير عدد النسخ في أي وقت.



ثانياً: إعدادات فواتير الأقسام (Department Receipts)



يقوم النظام بعد طباعة الفاتورة الرئيسية بطباعة فواتير مستقلة لكل قسم بالمطعم.



مثال:



الطلب يحتوي على:



بروست

عصير برتقال

شاورما دجاج

أرز



يقوم النظام تلقائياً بتقسيم الطلب إلى:



فاتورة قسم المطبخ:



بروست

أرز



فاتورة قسم الشاورما:



شاورما دجاج



فاتورة قسم العصائر:



عصير برتقال



كل قسم يحصل فقط على الأصناف الخاصة به.



ثالثاً: التحكم بعدد النسخ لكل قسم



من لوحة الإدارة يمكن تحديد عدد النسخ لكل قسم.



مثال:



المطبخ:



نسخة واحدة.

أو نسختان.



قسم العصائر:



نسخة واحدة.



قسم الشاورما:



ثلاث نسخ.



كل قسم مستقل تماماً.



رابعاً: اختيار الطابعة الخاصة بكل قسم



كل قسم يمكن ربطه بطابعة مختلفة.



مثال:



المطبخ

→ Kitchen Printer



العصائر

→ Juice Printer



الشاورما

→ Shawarma Printer



الحلويات

→ Dessert Printer



البار

→ Bar Printer



خامساً: إمكانية تعطيل الطباعة



لكل نوع طباعة خيار:



☑ تفعيل



☐ تعطيل



مثلاً:



طباعة فاتورة العميل

✓



طباعة فاتورة المطبخ

✓



طباعة قسم العصائر

✕



طباعة قسم الشاورما

✓



سادساً: ترتيب تنفيذ الطباعة



يمكن التحكم في ترتيب خروج الفواتير.



مثال:



1- فاتورة العميل.



2- فاتورة الكاشير.



3- فاتورة المطبخ.



4- فاتورة العصائر.



5- فاتورة الشاورما.



6- فاتورة الحلويات.



سابعاً: طباعة المجموعات (Groups)



كل صنف داخل النظام مرتبط بمجموعة.



مثال:



بروست

→ مجموعة المطبخ



أرز

→ مجموعة المطبخ



عصير

→ مجموعة العصائر



شاورما

→ مجموعة الشاورما



حلويات

→ مجموعة الحلويات



عند الطباعة يقوم النظام بتجميع الأصناف حسب المجموعة وإرسالها للطابعة الخاصة بها.



ثامناً: التحكم في شكل الفاتورة



لكل نوع فاتورة يمكن تحديد:



حجم الورق (80mm أو 58mm أو A4).

عرض الفاتورة.

إظهار او ادراجصورة  شعار المطعم.

إظهار ان وجد اسم الفرع.

إظهار رقم الطلب.

إظهار اسم تلقائي الكاشير.

إظهار رقم تلقائي الطاولة.



إظهار التاريخ والوقت.

إظهار QR Code.

إظهار الضريبة.

إظهار الخصومات.

إظهار الملاحظات.

إظهار الباركود.

إظهار حالة الطلب (سفري أو محلي أو توصيل).

تاسعاً: الطباعة التلقائية



يمكن التحكم في توقيت الطباعة:



✓ عند حفظ الطلب.



✓ عند الضغط على زر الطباعة.



✓ عند الضغط على Enter.



✓ بعد اعتماد الطلب.



✓ بعد الدفع فقط.



عاشراً: إعادة الطباعة



يمكن تحديد:



عدد مرات إعادة الطباعة المسموح بها.

تسجيل سبب إعادة الطباعة.

تسجيل اسم الموظف الذي أعاد الطباعة.

تسجيل وقت إعادة الطباعة.

الحادي عشر: سجل عمليات الطباعة



يقوم النظام بحفظ جميع عمليات الطباعة داخل سجل خاص يحتوي على:



رقم الطلب.

نوع الفاتورة.

اسم القسم.

اسم الطابعة.

وقت الطباعة.

الموظف.

عدد النسخ.

حالة الطباعة (نجحت أو فشلت).
