# نظام نقطة المبيعات — إتقان سوفت

نظام نقطة مبيعات متكامل باللغة العربية مع لوحة تحكم للمدير وواجهة الكاشير.

## تسجيل الدخول الافتراضي

| الدور | اسم المستخدم | كلمة المرور |
|-------|------------|------------|
| مدير النظام | `admin` | `admin123` |
| كاشير | `cashier` | `cashier123` |

## المتطلبات

- [Node.js](https://nodejs.org/) نسخة 20 أو أعلى
- [pnpm](https://pnpm.io/) نسخة 8 أو أعلى

```bash
npm install -g pnpm
```

## التثبيت والتشغيل

```bash
# 1. تثبيت الحزم
pnpm install

# 2. تشغيل الخادم الخلفي (API) — يعمل على المنفذ 8080
pnpm --filter @workspace/api-server run dev

# 3. في نافذة ثانية: تشغيل الواجهة الأمامية — يعمل على المنفذ 20639
PORT=20639 BASE_PATH=/ pnpm --filter @workspace/pos-system run dev
```

افتح المتصفح على: **http://localhost:20639**

> **ملاحظة:** قاعدة البيانات SQLite تُنشأ تلقائياً عند أول تشغيل في `artifacts/api-server/data/pos.db` مع بيانات تجريبية (15 منتج، 4 تصنيفات، 20 فاتورة).

## المزايا

### لوحة القيادة (المدير)
- ملخص مبيعات اليوم والشهر
- مخطط المبيعات حسب الساعة
- أكثر المنتجات مبيعاً

### نقطة البيع (الكاشير)
- شبكة منتجات مرقمة
- إضافة منتج برقمه + Enter
- دعم الدفع نقداً / شبكة / مختلط
- طباعة الفاتورة

### الإدارة
- المنتجات: إضافة / تعديل / حذف مع دعم الباركود والمخزون
- التصنيفات مع ألوان
- الطلبات والفواتير مع فلترة بالتاريخ
- العملاء وإجمالي مشترياتهم
- المستخدمين مع صلاحيات (مدير / كاشير)
- تقارير مبيعات يومية / شهرية / سنوية
- إعدادات النشاط التجاري والضريبة وإعدادات الفاتورة

## المكدس التقني

- **الواجهة:** React 19 + Vite + Tailwind CSS v4 + shadcn/ui
- **الخادم:** Express 5 + Node.js
- **قاعدة البيانات:** SQLite (better-sqlite3) — لا حاجة لأي إعداد خارجي
- **إدارة الحالة:** TanStack Query
- **المخططات:** Recharts
- **اللغة:** عربية كاملة مع دعم RTL
